Discount Code Batch Mint

Generate thousands of unique, human-typeable promo codes (no 0/O, 1/I confusion) in patterns like SPRING-XXXXXX, exported in Shopify and WooCommerce import format.

Runs 100% in your browser. Your files never leave this device.









How it works


    

  • Pattern builder: a prefix plus a run of X characters, with an unambiguous default charset so codes survive being read aloud or typed from a printed insert.
    • 

  • Codes are generated with crypto.getRandomValues and kept unique in memory, up to 50,000 per batch.
    • 

  • Paste your existing codes and any collision is excluded before export.
    • 

  • Optional checksum character helps support staff spot a mistyped code.
    • 

  • Export a plain list, a Shopify discount CSV or a WooCommerce coupon CSV.
    •
